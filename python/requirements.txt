# ノート化(§4.4.4)。activationはRMVPE由来の出力に差し替えて使う方針のため、
# basic_pitch自身のTF/ONNX/CoreMLモデルは使わず、note_creation等の後処理
# ユーティリティだけを使う想定。macOS + Python 3.11では、basic-pitchのPyPI
# メタデータ上どの条件付き依存(tensorflow-macos等)も適用されず、TF/ONNX
# バックエンド無しでインストールされる(importはwarningのみで成功する。
# 実測済み)。バックエンドが必要になった場合は `basic-pitch[onnx]` 等に
# 差し替えを検討する。
basic-pitch==0.4.0

# ボーカル/伴奏分離(§4.4.2 STEP2)。Kimberley Jensen版Mel-Band RoFormer

# ダウンロード・~/.cache参照を一切行わずオフラインで動作する。

# 歌詞のモーラ読み変換(§4.4.6 STEP6)。OpenJTalkのCython/C++バインディング。

# (npm run build:python-runtime実行前に `sudo xcodebuild -license` でXcodeの

# 動作確認ステップで一度g2pを呼び、ビルド時点で辞書取得まで完了させている
# (パッケージ後のアプリ実行時に改めてネットワークへ問い合わせることはない)。
pyopenjtalk==0.4.1
